# MediCube
### An ML-Driven Hospital Queue Management System

## About the Project

MediCube is an intelligent hospital queue management system designed to reduce patient waiting time and improve hospital queue organization.

The system helps hospitals manage both walk-in patients and appointments by providing estimated waiting-time ranges based on queue progress and patient flow.

It aims to improve transparency, reduce unnecessary waiting and support better coordination between receptionists, nurses and patients.

## Problem Statement

Traditional hospital queue systems often create long waiting times, confusion among patients and difficulty in managing emergency cases.

MediCube addresses these challenges through an organized digital queue management system with intelligent waiting-time estimation.

## Objectives

- Reduce patient waiting-time uncertainty.
- Organize walk-in and appointment queues.
- Estimate patient waiting-time ranges.
- Provide real-time queue status updates.
- Support emergency-related queue adjustments.
- Improve communication between hospital staff and patients.

## Key Features

- **Patient Queue Management:** Organizes patient appointments and walk-in registrations.
- **Waiting-Time Prediction:** Provides estimated waiting-time ranges instead of exact times.
- **Queue Display:** Displays current and upcoming queue progress.
- **Nurse Updates:** Allows nurses to update consultation status.
- **Emergency Handling:** Accounts for emergency-related delays.
- **Doctor Availability:** Supports queue status updates when a doctor is unavailable.

## System Workflow

1. Receptionist registers a patient and creates a queue entry.
2. The patient waits for their turn.
3. The system estimates the waiting-time range.
4. Patients can view the current queue progress.
5. Nurses update consultation status.
6. Queue information is updated based on consultation progress and delays.

## Installation and Setup

1. Clone the repository:

   ```bash
   git clone https://github.com/narmathasuresh2005-lab/Medicube.git
   ```

2. Open the project folder.

3. Install the required dependencies in the frontend and backend directories using their respective package.json files.

4. Configure the required environment variables locally using a `.env` file.

5. Start the frontend and backend using the scripts defined in their respective package.json files.

**Note:** Never upload `.env` files, database passwords or API keys to GitHub.
